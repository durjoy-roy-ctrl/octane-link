⛽ OctaneLink — Fuel Logistics & Trading Platform
OctaneLink is a full-stack MERN (MongoDB, Express, React, Node.js) web application designed for fuel logistics, buying/selling petroleum products, dynamic order analytics, and delivery tracking.

📁 Repository Structure
Octane-Link-Frontend: React client application (Vite UI)

Octane-Link-Backend: Node.js & Express REST API server

🚀 Key Features
User Authentication: Secure JWT-based Login, Signup, and Password Reset (ForgotPassword & ResetPassword with token link).

Delivery Management:

Retail: Live bike courier tracking with status timeline updates.

Wholesale: Scheduled tanker/truck delivery with route preview and slot booking.

Analytics Dashboard: Visual representation of orders, fuel statistics, and metrics.

Buy & Sell Hub: Marketplace workflow for retail fuel buying and bulk trading quotes.

🛠 Tech Stack
Frontend: React.js, React Router DOM, Vite, CSS3
Backend: Node.js, Express.js
Database: MongoDB
Authentication: JSON Web Tokens (JWT), Bcrypt

💻 Getting Started
1. Run the Backend
cd Octane-Link-Backend
npm instal
npm start
(Server runs on http://localhost:5000)

2. Run the Frontend
cd Octane-Link-Frontend
npm install
npm run dev
(Client runs on http://localhost:5173)
